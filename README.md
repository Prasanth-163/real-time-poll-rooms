# Real-Time Poll Application

## Overview
This is a full-stack real-time polling application built using Flask, PostgreSQL, and Flask-SocketIO. Users can create polls, share them, and vote with live updates.

## Features
- Create custom polls with multiple options
- Real-time vote updates using WebSockets
- Session-based and IP-based vote restriction
- PostgreSQL database integration
- Deployed on Render

## Tech Stack
- Backend: Flask
- Database: PostgreSQL
- Real-time: Flask-SocketIO
- Frontend: HTML, CSS, JavaScript
- Deployment: Render
